# Licences des composants du firmware Trinity — vérification du 2026-10-02

Question (bmarty, T-107) : le groupe AGI de Neo6502AGI est dérivé de Sarien (GPL). Le firmware combiné peut-il
être distribué sous la GPL, et avec quelle version ? Ce document relève les **faits** (fichiers de licence et
en-têtes lus sur le disque ou dans le dépôt de Sarien). **Ce n'est pas un avis juridique.**

## 1. Ce qui entre dans le binaire USB distribué (`trinity-0.16.70-fatfs-tiny-USB.uf2`)

| Composant | Licence (source lue) | Avec GPL v2 | Avec GPL v3 |
|---|---|---|---|
| Firmware de base (paulscottrobson, Trinity) | MIT (`LICENSE`) | compatible | compatible |
| pico-sdk 1.5.1 | BSD 3 clauses (`~/pico-sdk-1.5.1/LICENSE.TXT`) | compatible | compatible |
| TinyUSB 0.21.0 (+ patch T-100) | MIT (`LICENSE`) | compatible | compatible |
| PicoDVI (+ patchs Trinity) | BSD 3 clauses (`LICENSE`, Luke Wren) | compatible | compatible |
| FatFs R0.15 (`firmware/lib/fatfs`) | licence de ChaN, 1 clause de type BSD (`ff.c`) | compatible | compatible |
| NeoDOS 0.32.1 (embarqué, `neodos_binary.h`) | **EUPL 1.2** (`~/Neo6502Msdos/LICENSE`) | **oui par clause** : l'annexe de l'EUPL 1.2 cite « GPL v. 2, v. 3 » comme licences compatibles (art. 5) | idem |
| Police MDA du mode Hercules (T-67) | **CC BY-SA 4.0** (`firmware/scripts/assets/Bm437_IBM_MDA.LICENSE.txt`, VileR) | **non** (Creative Commons ne déclare CC BY-SA 4.0 compatible qu'avec la GPL v3) — voir § 3 | compatible (dans un seul sens) |
| Polices héritées de l'amont : MSX (dump de ROM `uk1msx048.ic37`), HD44780 (ROM de contrôleur LCD), « Daniel C. » | **aucune licence documentée** | inconnu | inconnu |

Hors du binaire USB : `no-OS-FatFS-SD-SPI-RPi-Pico` (carlk3) est sous **Apache 2.0**, incompatible avec la GPL v2
(compatible avec la GPL v3). Il n'est lié que dans la variante **carte SD** (`STORAGE_TYPE=SDCARD`,
`firmware/sources/CMakeLists.txt` l. 50-54), pas dans le binaire USB.

## 2. Sarien (source du code AGI)

- `src/picture.c` (dépôt cmatsuoka/sarien, branche master) : « Copyright (C) 1999-2001 Stuart George and Claudio
  Matsuoka … under the terms of the GNU General Public License as published by the Free Software Foundation; see
  docs/COPYING » — **aucun numéro de version dans l'en-tête**.
- `README` : « Sarien is covered by the Free Software Foundation's GNU Public License » — pas de version non plus.
- `doc/COPYING` : texte de la **GPL v2** (juin 1991).
- La GPL v2, article 9, prévoit : si le programme ne précise pas de numéro de version de la licence, on peut choisir
  n'importe quelle version publiée par la FSF. Savoir si livrer le texte de la v2 dans `doc/COPYING` vaut
  « préciser la version » est une **question d'interprétation** que je ne tranche pas.

## 3. Conséquences, pour la décision

- **Firmware combiné sous GPL v2** : les composants de code sont compatibles (NeoDOS par la clause de l'EUPL). Deux
  obstacles : la **police MDA CC BY-SA 4.0** (incompatible avec la v2 ; à remplacer, ou à traiter comme une donnée
  séparée, ce qui est une question juridique) et les **polices de l'amont sans licence documentée** (point flou qui
  existe déjà aujourd'hui, indépendamment de l'AGI).
- **Firmware combiné sous GPL v3** : levé pour la police MDA et pour Apache 2.0 ; possible seulement si Sarien peut
  être pris sous v3, ce qui dépend de l'interprétation du § 2 (ou d'un accord des auteurs).
- **Variante « Trinity + AGI » séparée** : Trinity reste sous MIT ; seule la variante porte la licence de Sarien.
  Les mêmes obstacles s'appliquent à la variante.
- **Réécriture en salle blanche** du décodeur : supprime la dépendance au code de Sarien ; les **tables** (formes du
  pinceau, motif « splatter ») restent copiées de Sarien, sans autre source libre trouvée par Neo6502AGI.

Références : [cmatsuoka/sarien](https://github.com/cmatsuoka/sarien) (`src/picture.c`, `README`, `doc/COPYING`),
[Sarien sur SourceForge](https://sourceforge.net/projects/sarien/).

## 4. Décision (bmarty, 2026-10-02)

Le décodeur dérivé de Sarien est abandonné. Il est remplacé par une réécriture en salle blanche de Neo6502AGI, sous
**EUPL 1.2**. bmarty accepte ces fichiers EUPL 1.2 dans le firmware Trinity, qui reste sous MIT. Livré en 0.16.71.
